安装MongoDB

一、使用Docker安装

1.1 创建容器

执行下列命令创建MongoDB容器：

-d 表示后台启动

--restart 表示docker启动时自启动相关容器

-p 映射端口，格式为主机端口:容器端口

--name 指定容器名称

-v 挂载目录，格式为主机目录:容器目录

--auth 开启MongoDB的授权模式

网上其他文章说先不开启此选项，等设置管理员后，再重启并设置此选项对docker来说过于麻烦

1.2 添加管理员

首先进入容器

根据阿里云帮助文档，在未开启认证的环境下，先输入mongo，进入命令模式，然后切换到admin数据库，并创建管理员账号，管理员账号将在system.users中。

关闭MongoDB服务：db.runCommand("shutdown")然后重启：mongod --auth。
